Flagship Project

Student Helpdesk: Automated Deployment on AWS

A website that goes live automatically on every code push, with no manual file copying.

Git push→GitHub→Jenkins→Docker→EC2 + Nginx
  • Packaged the site in a Docker (Nginx) container and ran it on an Ubuntu EC2 instance.
  • Created a 3-stage Jenkins declarative pipeline (Checkout, Build Image, Deploy) with GitHub Poll SCM for auto-deploy.
  • Secured the setup: IAM user with MFA, SSH limited to my IP, Jenkins port 8080 private via SSH tunnel, no keys or tokens in GitHub.
  • Used Ansible to automate Docker installation on the server.
  • Set up a CloudWatch CPU alarm (above 70% for 5 minutes) with SNS email alerts, a private encrypted S3 bucket for backups, and CloudTrail for auditing.
  • Troubleshot real issues: SSH permission errors, Docker permission denied in Jenkins, and port conflicts.
